## Plans

Prices are per workspace, in US dollars, each month. Detail: [Plans and limits](/account/plans).

| | Free | Pro | Teams |
| --- | --- | --- | --- |
| Price | \$0 | \$15 | \$49 |
| Servers | 1 | 3, up to 10 at \$3 each extra | 10, up to 50 at \$3 each extra |
| Apps and background services | 3 | 30 | 100 |
| Databases (PostgreSQL and Redis together) | 3 | 30 | 100 |
| Custom domains | None | 5, up to 30 at \$3 each extra | 10, up to 100 at \$3 each extra |
| Bandwidth a period | 10 GB, then apps pause | 2 TB, then \$0.01 per GB up to the spend limit | 5 TB, then the same |
| Database backups | No | Yes | Yes |
| Offsite backup storage | None | 200 GB, then \$0.03 per GB a month up to the spend limit | 1 TB, then the same |
| Offsite copies per database | None | Up to 3 (the newest) | Up to 3 (the newest) |
| Members | The owner | The owner | 5, up to 50 at \$5 each extra |

| Rule | Value |
| --- | --- |
| Spend limits (bandwidth, backup storage) | \$0 by default; \$1 allows 100 GB of bandwidth; 3 cents allow 1 GB of backup storage |
| Bandwidth banner | From 75% of the period's limit |
| Bandwidth emails | At 80%, and when apps pause at 100% |
| Bandwidth period | Calendar month on Free; billing period on Pro and Teams |
| Sizes | Decimal: 1 GB is 1,000,000,000 bytes |

## Who and what an action needs

| Action | Needs |
| --- | --- |
| Connect, remove, lock, patch, restart or update a server | Owner or Admin |
| Connect GitHub | Owner or Admin |
| Deploy, redeploy, stop a deployment | Owner, Admin or Developer |
| Run a command in an app | Owner or Admin, and the second factor again when two-factor sign-in is on |
| See Billing and People | Owner or Admin |
| Change the plan, extras, spend limits | Owner. Spend limits need two-factor sign-in turned on. |
| Custom domains, database backups, a second server | Pro or Teams |
| Invite people, roles | Teams |

Detail: [People and roles](/account/members-and-roles), [Two-factor sign-in](/account/two-factor).

## Servers

| What | Value |
| --- | --- |
| Systems | Ubuntu 22.04, 24.04, 26.04; Debian 12, 13; x86-64 or ARM64 |
| Comfortable start | 2 vCPU, 4 GB of memory |
| Server name | Up to 120 bytes, not starting with a dash |
| Enrollment code | Works once, for 30 minutes |
| Disk reserve | The larger of 2 GiB and 10% of the disk. Deployments wait below it. |
| Swap for builds | On servers under 2 GiB of memory with no swap: a 2 GiB file, 1 GiB on a smaller disk, none when the disk has no room |
| Deployments at once | 1 per server |
| Build maximum | 512 to 65,536 MiB and 0.1 to 16 cores, or **Use spare resources** |
| Build cache | The smaller of 10 GiB and 10% of the disk |
| Monitor history | 24 hours |
| Server silent before an email | 5 minutes |
| Security updates | Daily, 03:00 UTC by default. Restart at most weekly, Sunday 03:00 UTC by default, with an email at least 24 hours before. |
| Private SSH command | Works once, for 60 seconds |
| Private SSH sessions | 4 per server; 12 hours at most, 60 minutes idle |
| Lock test | 5 minutes, then it undoes itself unless kept |
| Agent update request | Expires after 1 hour |

Detail: [What server you need](/servers/requirements), [How memory is shared](/servers/memory), [The Security tab](/servers/security).

## Apps

| --- | --- |
| App name | 2 to 120 characters |
| Exact LiveHQ address | 2 to 40 lowercase letters, numbers or single hyphens |
| Memory limit | 128 MiB to 64 GiB; a new app starts at 512 MiB |
| CPU limit | 0.1 to 16 cores; a new app starts at 1 core |
| Health check | `GET` on the path (`/` by default); passes on two answers in a row with status 200 to 399, each within 3 seconds |
| Startup allowance | 120 seconds by default, 15 to 1,800 |
| Step retries | Up to 3 attempts. Not retried: the server ran out of memory, wrong port, listening on localhost only, a health check answered with a status from 400 to 499. |
| Source download (compressed) | 64 MiB |
| Source unpacked | 256 MiB; one file 64 MiB; 50,000 files and folders |
| Build output kept | 24 hours |
| Watch after going live | About 1 minute, previous release kept for rollback |
| Stopping a deployment | Takes effect within about 25 seconds |
| Restarts paused | After 5 restarts in 10 minutes |
| A server's report trusted for | 150 seconds |
| Restart history | 14 days |
| Usage charts | 15 minutes to 24 hours; history kept 24 hours |
| Logs | Latest 200 lines per read; one read per app every 10 seconds |
| Repositories listed | Up to 500 |

Detail: [Deploy an app](/apps/deploy), [How LiveHQ builds an app](/apps/builds), [Limits and usage](/apps/resources).

## Databases

| --- | --- | --- |
| Version | 17 | 8 |
